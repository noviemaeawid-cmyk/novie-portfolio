NOVIE.EXE — PERSONAL PORTFOLIO WEBSITE
=======================================

Files
- index.html : website content and sections
- style.css  : responsive Y2K/pastel styling
- script.js  : mobile navigation and small interactions

PREVIEW ON YOUR COMPUTER
1. Download and unzip novie-y2k-portfolio.zip.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
   (Internet is needed for the optional Google Fonts; the site still works without them.)

BEFORE YOU PUBLISH
1. Add your actual social profile URLs in index.html. Search for:
   INSTAGRAM ↗, TIKTOK ↗, FACEBOOK ↗
   Replace each href="#" with the full public profile URL.
2. Replace the creative concept mockups with links/screenshots of your real work if available.
3. Verify the achievement numbers and update them if needed.
4. Optional: replace the N avatar tile with a photo. For a quick change, you can keep the letter avatar.
5. Check that your email address is correct.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository named novie-portfolio.
3. Upload index.html, style.css, and script.js from this folder to the repository root.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes. GitHub Pages will show your website URL on the Pages settings screen.
   It will usually look like https://YOUR-USERNAME.github.io/novie-portfolio/
8. Open the URL and test every section and the email link.

You can also publish with Netlify by dragging the unzipped folder into its manual deploy/drop area
after signing in at https://app.netlify.com/drop (the exact UI may change).

NOTES
- The email button uses mailto and opens the visitor's default email app; it is not a contact form.
- This is a static website: no database or server is required.
- This portfolio is a starter draft. The creative tiles are visual concept mockups, not claims of
  completed client projects. Add real work samples when ready.
